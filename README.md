# E.B.E.'s Drum Splitter

E.B.E.'s Drum Splitter is an iOS app designed to separate individual drum sounds from an audio track.

## Goal

Import a song or drum break and isolate drum elements such as:

- Kick
- Snare
- Hi-Hat
- Cymbals
- Other percussion

Users will be able to listen to and export the separated drum stems.

## Platform

iPhone / iOS

## Status

Currently in development.
